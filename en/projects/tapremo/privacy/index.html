Tapremo privacy policy

How the Android app handles local information and how you can manage it.

Tapremo does not use accounts, analytics, telemetry, Bluetooth or location.

Information stored on your device

The app stores TV records, TV/room/routine names entered by the user, routine steps, remote shortcuts, app preferences and button test notes on the device. The language preference is also stored on the device. This information is not automatically sent off the device. Android may delete it when the app is uninstalled.

During recovery, a copy of the last unreadable settings file may be kept in the app's private storage. TV files and single-routine files prepared for sharing are kept in separate cache folders, with up to the 10 most recent files of each type retained. Android may clear this cache. The receiving app is given temporary read access only to the shared file. An unsaved routine draft is kept in Android's saved screen state so it can be restored when the screen is recreated. Deleting a TV record or clearing the app's data provides ways to remove local information.

Sharing and backups

If the user chooses, they can save their TVs, routines, remote shortcuts and preferences in a JSON file, or send the file to an app selected through Android's share sheet. A single routine can also be shared as a separate file. TV files include TV/room/routine names and button test notes entered by the user; a single-routine file includes its name, steps and associated remote profile. The selected file provider or receiving app has its own network and privacy behaviour. This app does not perform automatic cloud backups. Users are responsible for deleting exported files; uninstalling the app does not delete those files.

Optional diagnostics

Local diagnostics is off by default. If the user enables it, up to 100 technical IR transmission records are held in process memory for no longer than 10 minutes. Records contain profile/command identifiers, frequency/duration summaries, result types and logical press positions. TV/room/routine names, serial numbers and raw platform error messages are not recorded. Disabling diagnostics or clearing the log deletes the records. The log is lost when the process ends. The report preview shows the user the phone model, Android/app versions and the description they entered. Sharing takes place only through the Android share sheet opened by the user.

Infrared permission

Tapremo uses Android's IR permission to send signals through the phone's built-in infrared emitter. Android does not show a separate permission prompt for this. Android also defines an internal permission to protect in-app broadcast receivers. This protection does not give access to personal data or additional hardware.
